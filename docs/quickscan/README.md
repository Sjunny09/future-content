# Future Content Quickscan — Documentatie

Dit is de volledige documentatie van het Quickscan-project (futurecontent.nl/scan).

De Quickscan is Future Content's binnenkomst-funnel: MKB-ondernemer vult website-URL in, op achtergrond scrapet het systeem de site en analyseert Claude het bedrijf (branche, niche, huisstijl, kansen). Op voorgrond ziet de klant 30-60s dynamische observatie-slides. Daarna 6 adaptieve vragen. Einde: belofte van 2-min Loom-video binnen 24u + optionele €495 pilotweek.

## De kernidee in één zin
*Laat me even naar je bedrijf kijken.* Spiegel van buiten, door iemand die er dagelijks naar kijkt — geen AI-scan, geen audit, geen PDF.
